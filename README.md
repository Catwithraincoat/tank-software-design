# tank-software-design

Ветка `hometask-5` добавляет случайно сгенерированные AI-танки.
Игрок управляет своим танком стрелками или клавишами WASD, а AI выбирает
случайное направление перед каждым ходом.

Управление реализовано шаблонами «Команда» и «Стратегия». Во время движения
танк резервирует исходную и целевую клетки, поэтому другие танки не могут
проехать сквозь него или занять одну из этих клеток.

```shell
./gradlew test
./gradlew run
```
