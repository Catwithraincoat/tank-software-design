# tank-software-design

Ветка `hometask-6`: танки двигаются, стреляют и получают урон.
Управление: стрелки / WASD — движение, пробел — стрельба.
Удержание пробела повторяет выстрел раз в 0,4 секунды. Стрельба выполняется
между перемещениями по клеткам; пробел имеет приоритет над направлением.
Повернуться к занятой клетке можно без перемещения — это позволяет
стрелять по противнику, стоящему вплотную.

У танка по умолчанию 100 HP, у пули — 50 единиц урона; оба значения можно
задать при создании танка. При HP ≤ 0 танк удаляется и освобождает обе
занятые клетки. Деревья неразрушимы, пуля исчезает при попадании в дерево,
танк или другую пулю, а также при выходе за границу уровня.

«Команда» (`MoveTankCommand`, `ShootTankCommand`) и «Стратегия» отделяют
выбор действий от исполнения. AI выбирает движение или стрельбу случайно.
Локальный `SimpleRecommendationEngine` дополнительно рекомендует выстрел,
если впереди виден танк; `RecommendationTankControlStrategy` адаптирует
рекомендации к игровым командам. Внешнего рекомендательного сервиса проект
не требует.

`LogicalLevel` владеет объектами и уведомляет `GraphicalLevel` об их
добавлении и удалении через `LevelListener` («Наблюдатель»). Начальная
загрузка и изменения во время игры используют одинаковые уведомления.
Логические объекты не создают текстуры и проверяются без OpenGL.

Цикл кадра: сбор команд → выполнение команд → `live(tick)` → отрисовка.
Танк резервирует исходную и целевую клетки до окончания движения.
Пуля создаётся в следующей клетке по направлению танка; попадание в упор
проверяется сразу. При большом tick проверяются все пройденные клетки,
включая встречные пули, которые меняются клетками.

Требуется JDK 17 или новее. Команды для Windows:

```shell
.\gradlew.bat test
.\gradlew.bat run
```
